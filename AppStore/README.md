# Mila App Store listing assets

Public Hebrew/English listing copy is under `metadata/`. Product screenshots are under `screenshots/` and `asc/screenshots/`; the app icon and listing preview are included here too. Demo screenshot text is illustrative, not a claim about recognition accuracy.

- [Support](https://github.com/buzagloidan/mila/blob/main/SUPPORT.md)
- [Privacy](https://github.com/buzagloidan/mila/blob/main/PRIVACY.md)
- [App Store Connect](https://appstoreconnect.apple.com/apps/6824172039/distribution/reviewsubmissions)

Version 1.0/build 2 was submitted on 18 October 2026. Manual release after Apple approval is enabled. See the root README and TEST_RESULTS.md for the source release and validation history.

Signing files, private review contacts, upload/submission receipts, account screenshots, export configuration and distribution packages stay local and are ignored by Git. Maintainers retain local operational records separately. `scripts/validate_store_package.py` requires those local records; it is not needed to build or test the public source.
